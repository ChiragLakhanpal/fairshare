# Platform limits met while building

Recorded as they are hit, with the date. Nothing here is from a doc page; those are in the plan.

| Date | Platform | Limit or behaviour | Effect | Workaround |
|---|---|---|---|---|
| 2026-10-11 | DuckDB 1.5 | One writer per file; a read-only reader blocks a writer | The app and a rebuild cannot run at the same time | App opens read-only; `lakehouse/run.py` sets `FAIRSHARE_WRITE=1`; summaries live in a separate small file |
| 2026-10-11 | DuckDB / Databricks SQL | Column aliases are case-insensitive | `T_now` and `t_now` collided in the decomposition and the shares came out 9x too small | Distinct names (`tot_now`); noted in CLAUDE.md rule 5 |
| 2026-10-11 | Streamlit | `$...$` in markdown renders as LaTeX | Dollar amounts turned into italic maths | `esc()` in `app/common.py` on every prose string |
| 2026-10-11 | Databricks Free Edition | Personal access token dialog spun for a minute and never returned the token | No PAT | OAuth as the user through the system browser (SDK `auth_type=external-browser`, cached); the SQL connector takes the SDK's header factory |
| 2026-10-11 | databricks-sql-connector | DDL through the connector blocked without end | Build hung | DDL goes through the Statement Execution API with a bounded wait; the connector is used for SELECTs only |
| 2026-10-11 | Databricks metric views | A dimension named `agency` and a join alias named `agency` collide (`agency.agency_name` read as a field of a STRING) | View creation failed | Join aliases `ag`, `mkt`, `cap` |
| 2026-10-11 | Genie Create Space API | Every list must be sorted by id or identifier; exactly one text instruction item; list-of-lines fields are concatenated with no separator | Four rejected payloads | One text block, one element per text field, lists sorted recursively |
| 2026-10-12 | Databricks Free Edition | Starter warehouse auto-stops after 10 minutes; the setting is not editable on free accounts; Genie then waits in PENDING_WAREHOUSE far longer than a direct start (8 s) | Genie calls timed out after idle periods | The Genie tool starts the warehouse first; `python -m harness.keepwarm` during a demo |
| 2026-10-12 | Databricks metric views | The YoY window measure (`offset: -12 month` on sales_month) is only right when the query groups by sales_month; at quarter grain it returned +350% | A wrong number that was nonetheless "from a query" | Genie instruction and a trusted quarter example that computes the change in SQL; measure comment says month grain |
| 2026-10-11 | Microsoft Foundry | The dated Azure OpenAI api-version path answered "API version not supported"; gpt-4.1-mini is marked Legacy in the catalog | First model calls failed | The `/openai/v1` OpenAI-compatible surface with the key as bearer; deployment `gpt-5-mini` (GA) |
| 2026-10-11 | Foundry portal | The SPA stops answering the Chrome extension after the first navigation | Could not read the deployments page | Used the deployments API with the key instead |
| 2026-10-12 | Homebrew on this Mac | `brew install azd` fails (Tier 3 configuration, no bottle) | No Azure Developer CLI yet | Install from Microsoft's script or a release binary before the Foundry hosting step |
| 2026-10-13 | Databricks Free Edition | Genie App Builder (Beta) needs the Previews page and account-level partner-AI settings; the workspace has no Previews page, no Build tab on Apps, and the app-spaces API answers empty | No natural-language app building here | The Streamlit app is deployed as a classic Databricks App; App Builder is a talking point (App Spaces as the governance boundary for sales-team-built views) |
| 2026-10-13 | AI/BI dashboard JSON | Text lines are concatenated without a separator; table columns need the full property set or the widget says "no fields selected"; tables are row views (no aggregation); widget expressions take simple aggregates only (a two-ratio difference and `number-plain` were rejected, string literals in CASE come back NULL, booleans work) | Six publish-and-look rounds | `lakehouse/dashboard.py`: ratios as dataset columns for tables, additive pieces plus `SUM()/SUM()` for tiles, a per-row `share_chg_pts` averaged per agency, a boolean for the bar colour |
| 2026-10-13 | AI/BI dashboard editor | The draft editor previews a widget expression as its first aggregate (`SUM(a)` instead of `SUM(a)/SUM(b)`); the published page evaluates the whole expression | The editor shows wrong tiles; viewers see the right ones | Check the published page, not the editor; the JSON file is the source of truth |
| 2026-10-13 | AI/BI dashboard | Clicking a bar selects it for Ask Genie and does not cross-filter the other datasets; the first load after a publish takes about a minute on the 2X-Small warehouse | One click is not enough in the demo | Pick the agency in the Agency filter (the URL then carries the filter, so the Harbor view has its own link); open the dashboard before the call |
| 2026-10-13 | Databricks console | Shows "Automated browser control detected" once the Chrome extension drives it and later steps hang | Could not publish or edit from the UI by automation | Everything through the API: `lakeview.update` and `publish`; the Genie link lives in `uiSettings.genieSpace.overrideId` in the dashboard JSON |
| 2026-10-13 | Databricks Apps | `pip install` of the `agent-framework` metapackage (thirty integrations) failed in the app runtime | First deployment failed with "Error installing packages" | The upload step writes a lean `requirements.txt` (core, openai, streamlit, SDK, SQL connector) |
| 2026-10-13 | Databricks model serving | `OpenAIChatClient` speaks the Responses API: "passthrough is not supported for model databricks-gpt-oss-120b"; through chat completions the reasoning models (gpt-oss, qwen3.5) return content as reasoning+text parts the framework drops, so the final answer was empty | No answer text | `OpenAIChatCompletionClient` and `databricks-llama-4-maverick` (plain content, tool calling) for the Databricks model branch |
| 2026-10-13 | Databricks Apps | Up to 3 apps, stopped 24 hours after a start or deploy; the viewer's forwarded token is per request, so a cached SQL connection or model client holds a token that expires | A stale app after a day; a stale token after an hour of one session | `python lakehouse/app_deploy.py start` before a demo; the agent is cached per token and the SQL connector resolves headers per request |
| 2026-10-14 | Databricks serverless jobs | A Python script task is run through `exec()` inside a kernel: `__file__` is undefined, so a script cannot locate its own repo | The parity task died on its first line; the service retried once with the same result | The bundle passes `--root ${workspace.file_path}` and `lakehouse/job_tasks.py` puts it on `sys.path` |
| 2026-10-14 | Databricks serverless jobs | The kernel that runs a Python script task already has an asyncio loop running, so `loop.run_until_complete` raises "Cannot run the event loop while another loop is running" | The Monday draft task failed at the first model call | `harness/aio.py` keeps one loop for the process and, when a loop is already running on the calling thread, runs ours on its own thread (`run_coroutine_threadsafe`) |
| 2026-10-14 | Databricks Apps | A stopped app refuses a deployment ("not in RUNNING state"), and starting it redeploys the last snapshot first, during which a new deployment is refused ("active deployment in progress") | Two failed deploys after the 24-hour stop | `app_deploy.py deploy` starts a stopped app and waits for the pending deployment before deploying |
